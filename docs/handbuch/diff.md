# Differences between handbook and specification

- `audit-log` — Handbook: The audit log is revision-proof. Spec/code: The feature only aggregates source histories; no immutability guarantee exists. Evidence: `docs/handbuch/14-rechte-seitenleiste.md#kapitel-6-2-4`; `02-backend/features/protocol_service/README.md`.
- `audit-log` — Handbook: It records all user and AI actions. Spec/code: It reads the configured logical audit sources from the shared database. Evidence: `docs/handbuch/05-gesamtverfahrensuebersicht.md#kapitel-5-1-3`; `02-backend/features/protocol_service/src/routes/read-history.ts`.
- `pdf-redaction` — Handbook: The agent redacts personal data and other protected or identifying information. Spec/code: Detection uses configured categories only. Evidence: `docs/handbuch/13-schwaerzungsagent.md#kapitel-6-1`; `05-modulcluster/modul-anonymisierung/src/prompts/pii_config.json`.
- `pdf-redaction` — Handbook: Manual review is recommended. Spec/code: The UI requires verification before further processing or sharing. Evidence: `docs/handbuch/13-schwaerzungsagent.md#kapitel-6-1`; `01-frontend/frontend/src/features/schwaerzungsagent/de-schwaerzungsagent.json`.
- `versioning` — Handbook: Users can optionally start follow-up analysis after approving updated documents. Spec/code: A successful later version automatically starts its version-scoped FVP workflow. Evidence: `docs/handbuch/08-einzelverfahrensuebersicht.md#kapitel-5-2-12`; `packages/core/projects/src/temporal/workflow-logic.ts`.
- `versioning` — Handbook: The initial-upload dialog closes automatically after processing. Spec/code: The completed flow waits for the user to select its close action. Evidence: `docs/handbuch/07-verfahren-anlegen-und-upload.md#kapitel-5-2-10`; `01-frontend/frontend/src/features/project/overview-screen/documents-update-dialog/steps/UploadSuccessStep.tsx`.
- `main-page` — Handbook: The dashboard list contains only assigned procedures. Spec/code: It defaults to all returned procedures and offers an owner/member filter. Evidence: `docs/handbuch/06-anmeldung-und-navigation.md#kapitel-5-2-3`; `01-frontend/frontend/src/features/main-page/list-screen/projects-table/ProjectsTable.utils.ts`.
- `main-page` — Handbook: Search covers name, file reference, and status; filters cover type, status, and favorites. Spec/code: Search also covers type; filters also cover source and assignment. Evidence: `docs/handbuch/06-anmeldung-und-navigation.md#kapitel-5-2-5`; `01-frontend/frontend/src/features/main-page/list-screen/projects-table/ProjectsTable.utils.ts`.
- `main-page` — Handbook: All listed applicant fields are required. Spec/code: Only street, house number, postal code, city, and country are required. Evidence: `docs/handbuch/07-verfahren-anlegen-und-upload.md#kapitel-5-2-7`; `01-frontend/frontend/src/features/project/data/project-details-form/projectForm.schema.ts`.
- `ewms` — Handbook: The `E`, `S`, or `N` prefix is followed by a four-digit number. Spec/code: Validation requires four initial digits but accepts more digits or characters afterward. Evidence: `docs/handbuch/11-behoerden-und-oeffentlichkeitsbeteiligung.md#kapitel-5-2-15-1`; `packages/core/documents/src/temporal/activities.ts`.
- `ewms` — Handbook: All CSV information except the response column must remain unchanged for re-import. Spec/code: Import reads only `Argument-ID` and non-empty `Erwiderung` values and ignores other columns. Evidence: `docs/handbuch/11-behoerden-und-oeffentlichkeitsbeteiligung.md#kapitel-5-2-15-2`; `02-backend/features/objections_management_service/src/csv.ts`.
- `mvp-topic-detail` — Handbook: The selected legal bases apply across projects. Spec/code: Legal bases are saved for one project, version, and topic. Evidence: `docs/handbuch/10-materielle-vollstaendigkeitspruefung.md#kapitel-5-2-14-1`; `01-frontend/frontend/src/features/project/mvp/topic-detail-screen/screen-content/rechtsgrundlage-dialog/saveNormSelectionChanges.ts`; `02-backend/features/examination_service/src/routes/legal-basis.ts`.
- `feedback` — Handbook: A rating can be saved without a further assessment. Spec/code: A reason matching the rating is required. Evidence: `docs/handbuch/10-materielle-vollstaendigkeitspruefung.md#kapitel-5-2-14-2`; `01-frontend/frontend/src/features/feedback/feedbackFormSchema.ts`.
- `law-change` — Handbook: MVP markers cover relevant legal changes since the procedure started. Spec/code: Matching uses all pending records without a project or procedure-start filter. Evidence: `docs/handbuch/10-materielle-vollstaendigkeitspruefung.md#kapitel-5-2-14`; `01-frontend/frontend/src/features/project/law-changes/data/collections/lawChanges.collection.ts`.
- `law-change` — Handbook: RPB law-change markers provide an icon with a tooltip. Spec/code: Per-norm markers open a detailed dialog; only aggregated markers provide a tooltip. Evidence: `docs/handbuch/12-rechtliche-pruefung-und-beschlusserstellung.md#kapitel-5-2-16`; `01-frontend/frontend/src/features/project/law-changes/ui/LawChangeIndicator.tsx`, `01-frontend/frontend/src/features/project/law-changes/ui/AggregatedLawChangeIndicator.tsx`.
- `fvp-pp` — Handbook: Cross-document comparison occurs only when one document is the explanatory report. Spec/code: Candidate retrieval also searches a broader project-wide claim pool. Evidence: `docs/handbuch/09-formale-vollstaendigkeitspruefung.md#kapitel-5-2-13-5`; `05-modulcluster/modul-plausibilitaet-pruefung/src/activities/risk_screener.py`.
- `fvp-pp` — Handbook: Identified passages are highlighted in document previews. Spec/code: The preview opens the stored page and shows the excerpt separately without highlights. Evidence: `docs/handbuch/09-formale-vollstaendigkeitspruefung.md#kapitel-5-2-13-5`; `01-frontend/frontend/src/features/project/fvp/plausibility-check/contradiction-card-expanded/InlinePdfViewer.tsx`.
- `mvp-overview` — Handbook: The overview shows all topics in the procedure. Spec/code: The overview excludes topics with `show_in_mvp` set to `false`. Evidence: `docs/handbuch/10-materielle-vollstaendigkeitspruefung.md#kapitel-5-2-14`; `01-frontend/frontend/src/features/project/mvp/overview-screen/TopicsOverviewScreen.tsx`.
- `rpb` — Handbook: The decision editor shows only the selected outline item's text. Spec/code: The editor shows the complete structured decision and focuses the selected section. Evidence: `docs/handbuch/12-rechtliche-pruefung-und-beschlusserstellung.md#kapitel-5-2-16`; `01-frontend/frontend/src/features/project/rpb/beschluss-swimlane/BeschlussEditor.tsx`.
- `rpb` — Handbook: Selecting an argument card opens details for the argument, response, and classification. Spec/code: The card shows the reference, text, and inclusion status without a detail action. Evidence: `docs/handbuch/12-rechtliche-pruefung-und-beschlusserstellung.md#kapitel-5-2-16-4`; `01-frontend/frontend/src/features/project/rpb/ai-assistance-swimlane/participation/AiParticipationArgumentCard.tsx`.
- `fvp` — Handbook: Request actions add hints directly to the request list. Spec/code: They open prefilled drafts; persistence occurs only after each form is saved. Evidence: `docs/handbuch/09-formale-vollstaendigkeitspruefung.md#kapitel-5-2-13`; `01-frontend/frontend/src/features/project/fvp/main-screen/cards/TableOfContentsResultCard.tsx`; `01-frontend/frontend/src/features/project/nachforderungen/sidebar-panel/RequestForm.tsx`.
- `nachforderung` — Handbook: Both request lists group entries by review step and document name. Spec/code: Both views show one flat creation-time list and hide source metadata. Evidence: `docs/handbuch/14-rechte-seitenleiste.md#kapitel-6-2-2`; `01-frontend/frontend/src/features/project/nachforderungen/sidebar-panel/RequestList.tsx`.
- `nachforderung` — Handbook: PDF and Word controls download files. Spec/code: Word downloads `.docx`; PDF opens a browser print dialog without a direct download. Evidence: `docs/handbuch/14-rechte-seitenleiste.md#kapitel-6-2-2-1`; `01-frontend/frontend/src/features/project/nachforderungen/export/exportPdf.ts`.
- `project-overview-screen` — Handbook: The project information card shows the procedure status. Spec/code: The card omits status and shows the original creation date instead. Evidence: `docs/handbuch/08-einzelverfahrensuebersicht.md#kapitel-5-2-11`; `01-frontend/frontend/src/features/project/overview-screen/project-details-card/ProjectDetailsCard.tsx`.
- `project-overview-screen` — Handbook: Users can change the federal state in project editing. Spec/code: The edit form displays the federal state as a disabled control and never patches it. Evidence: `docs/handbuch/08-einzelverfahrensuebersicht.md#kapitel-5-2-12-1`; `01-frontend/frontend/src/features/project/overview-screen/project-details-card/ProjectDetailsEditForm.tsx`.
- `project-overview-screen` — Handbook: `Zum Verfahren` becomes available only after documents are uploaded. Spec/code: The overview always renders the formal-completeness link after project data loads. Evidence: `docs/handbuch/08-einzelverfahrensuebersicht.md#kapitel-5-2-11`; `01-frontend/frontend/src/features/project/overview-screen/ProjectOverviewNavbarSection.tsx`.
- `project-overview-screen` — Handbook: Confirmation opens a next step where users can rerun formal-completeness and plausibility checks as needed. Spec/code: A later version starts the complete FVP workflow automatically, while the dialog only offers a link. Evidence: `docs/handbuch/08-einzelverfahrensuebersicht.md#kapitel-5-2-12`; `packages/core/projects/src/temporal/workflow-logic.ts`; `01-frontend/frontend/src/features/project/overview-screen/documents-update-dialog/steps/AiProcessesStep.tsx`.
- `project-comments` — Handbuch: Kommentare sind nach Prüfschritt gruppiert. Spezifikation/Code: Die Seitenleiste zeigt eine einzige, aufsteigend nach Erstellungszeit sortierte Liste. Belege: `docs/handbuch/14-rechte-seitenleiste.md#kapitel-6-2-3`; `01-frontend/frontend/src/features/project/comments/sidebar-panel/CommentsPanel.tsx`.
- `project-pdf-workspace` — Handbuch: Das Schließen-Icon schließt die maximierte Vergleichsansicht. Spezifikation/Code: Schließen entfernt nur eine manuelle Dokumentansicht; Minimieren stellt den verbundenen Arbeitsbereich wieder her. Belege: `docs/handbuch/10-materielle-vollstaendigkeitspruefung.md#kapitel-5-2-14-4`; `01-frontend/frontend/src/features/project/pdf-popout/popout/PdfPopoutPaneHeader.tsx`.
- `application-navigation` — Handbuch: Jedes favorisierte Verfahren zeigt Verfahrensname und Aktenzeichen. Spezifikation/Code: Die Favoritenkarte zeigt das Aktenzeichen erst nach dem Aufklappen. Belege: `docs/handbuch/06-anmeldung-und-navigation.md#kapitel-5-2-4`; `01-frontend/frontend/src/features/app-shell/navigation/NavProjectCard.tsx`.
