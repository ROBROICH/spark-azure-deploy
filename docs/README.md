# Documentation

Documentation is a core part of SPARK Workflow. It enables transparent evaluation, responsible use and operation, and sustainable development. This index provides a repository-wide overview of the available documentation and distinguishes each resource by its purpose, target audience, and language.

| Documentation resource | Purpose | Target audience | Language |
| --- | --- | --- | --- |
| [Technical product data sheet](./Technischer_Produktsteckbrief_GER_v1.pdf) | Provides a concise two-page overview of key technical characteristics, prerequisites, and operating conditions for initial orientation. For detailed architecture and dependencies, refer to the system architecture documentation. | Prospective operators | DE |
| Feature lists ([DE](./feature-list-ger.md) / [EN](./feature-list-en.md)) | Provide a concise overview of the functional scope of SPARK Workflow. | Product evaluators | DE / EN |
| [User manual](./Benutzerhandbuch_GER_v1.pdf) | Provides step-by-step guidance for using SPARK Workflow and serves as a practical reference for day-to-day work. | Public authority users | DE |
| [System architecture documentation](./system-architecture/README.md) and [architecture diagram](./system-architecture/system-architecture.png) | Describe the system architecture, its components, external dependencies, and operating requirements. | Software architects | DE |
| README files for the [frontend](../01-frontend/frontend/README.md), [services](../02-backend/), [shared services](../04-shared-services/), [modules](../05-modulcluster/), [Helm charts](../helm/charts/README.md), and [GitLab CI](../.gitlab/ci/README.md) | Explain the structure, configuration, development, operation, and dependencies of individual components; selected README files include Mermaid diagrams. | Developers and operators | EN |
| [Open-source roadmap](./roadmap.md) | Documents the scope of the two major historical open-source releases. Future features and planning updates are announced through repository issues. | Open-source community | EN |

**Language codes:** DE = German, EN = English
