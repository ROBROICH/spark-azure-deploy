# Documentation

Documentation is a core part of SPARK Workflow. It enables transparent evaluation, responsible use and operation, and sustainable development. This index provides a repository-wide overview of the available documentation and distinguishes each resource by its purpose, target audience, and language.

| Documentation resource | Purpose | Target audience | Language |
| --- | --- | --- | --- |
| [Technical product data sheet](./SPARK_Workflow_Technischer_Produktsteckbrief_v0-3-0.pdf) | Provides a concise two-page overview of key technical characteristics, prerequisites, and operating conditions for initial orientation. For detailed architecture and dependencies, refer to the system architecture documentation. | Prospective operators | DE |
| Feature lists ([DE](./feature-list-ger.md) / [EN](./feature-list-en.md)) | Provide a concise overview of the functional scope of SPARK Workflow. | Product evaluators | DE / EN |
| [User manual](./handbuch/README.md) | Provides step-by-step guidance for using SPARK Workflow and serves as a practical reference for day-to-day work. | Public authority users | DE |
| [System architecture documentation](./system-architecture/README.md) and the [C4 architecture views](./system-architecture/views/) | Describe the system architecture, its components, external dependencies, and operating requirements. The views are rendered from a versioned model; each `.svg` has its `.d2` source beside it. | Software architects | DE |
| [Backend application](../02-backend/apps/spark-backend/README.md) | Explains how the TypeScript backend is built from feature packages, and how to configure and run it. | Developers and software architects | EN |
| README files for the [frontend](../01-frontend/frontend/README.md), [services](../02-backend/), [shared services](../04-shared-services/), [modules](../05-modulcluster/) and [Helm charts](/helm/charts/README.md) | Explain the structure, configuration, development, operation, and dependencies of individual components; selected README files include Mermaid diagrams. | Developers and operators | EN |
| [Feature documentation](./features/) | Groups durable product-feature identity, detailed German user stories, and optional scalable Feature Briefs for Fach- and Legal review. | Product, Legal, and delivery teams | DE / EN |

**Language codes:** DE = German, EN = English
