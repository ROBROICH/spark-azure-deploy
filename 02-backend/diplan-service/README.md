# Dienst DiPlanintegration (diplan-service)
Service to integrate SPARK Workflow into DiPlan.
> **Disclaimer:** This directory is intentionally empty in the open-source release.
>
> The DiPlan service is an adapter that connects individual SPARK Workflow modules to the DiPlan platform. It has no function beyond that integration and is therefore not part of this repository.
>
> Some references to the service remain in the codebase. They concern only the DiPlan integration and are not required to build, deploy, or operate the open-source components. No replacement for the adapter is needed to run SPARK Workflow without DiPlan.
>
> In the long term, all services that connect SPARK Workflow to external platforms – including this adapter – are planned to be moved out of the main repository into separate repositories.
